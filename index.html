Baltic Evidence Showcase

Verifiable evidence chains for large-scale ecological modelling.

The Protect Baltic WP3 species distribution models are published, versioned and citable — 630 species, 7 product families, 4 410 raster products across fish, macrophytes and invertebrates. A DOI identifies the dataset. It does not identify a claim derived from it. This showcase follows one 250 m cell of the Baltic down to a single value and shows which evidence travels with it, and which does not.

How EVE was used in this research showcase

EVE was not used to generate the ecological models, and it does not determine whether they are scientifically correct. It was used as the verification framework for separating and binding the parts of the evidence chain.

  • Published source
  • Retrieved artefact
  • Measured identity
  • Product role
  • Model context
  • Review evidence
  • Declared claim
  • Reproduced verification result

Keeping those layers apart surfaced four things that are easy to lose in ordinary analysis:

Review context does not travel

A cited cell value carries no trace of the expert review recorded for that species — including notes the modelling team wrote themselves.

Raster values are not comparable across species

The binary threshold is derived per species, so a higher raster value can carry a worse suitability class.

Content identity is not role

Where two product families hold the same content, a content hash gives both the same identity and cannot establish which role an artefact played.

A verified value is not a known meaning

A predictor's name and value can be read and reproduced from the artefact, while what the value means is recorded in none of the published evidence examined.

EVE separates these layers so that one cannot silently stand in for another.

  • EVE did not generate the ecological models.
  • EVE does not determine scientific truth.
  • This showcase uses EVE's evidence-verification principles; it was not produced by a finished EVE runtime.

What this does not claim. A verification result says a declared relation holds against bound evidence. It is not a scientific, environmental or policy conclusion. Nothing here says a model is right or wrong: model metrics and expert review answer different questions and both can be reasonable within their own role.

How the data was obtained. Eight rasters and two CSV files were retrieved by HTTP byte range — 26 MB of a 5.58 GB archive — with CRC32 verified against the archive's own central directory after decompression. The sha-256 values are local measurements and are not published by Zenodo. Measured 2026-09-09. The two predictor stacks (Zenodo record 21523969) were not downloaded: for each, only the TIFF directory at the end of the file and the row strip examined were read by HTTP byte range. The archive inventory and the product-role measurement are published in measurements/.
